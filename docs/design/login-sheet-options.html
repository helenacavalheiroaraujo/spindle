Story 27 · Log in without leaving the page. Today, Buy, Add to cart and Sell open a separate log-in screen. In all three options a window opens on top of the page the user was on. After logging in or creating an account, the original action goes on (checkout, add to cart, sell flow), as it does today. Closing the window returns to the page exactly as it was, with nothing bought or added.

Option A · Centred window, log in first

A small window with the record the user was buying and the log-in form. “Create an account” is a link under the button that swaps the form in the same window. On phone the window is a sheet that rises from the bottom.
