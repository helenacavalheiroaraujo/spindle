3 · Cancel a paid order

Only while the order is "Paid" (not yet shipped). Cancelling puts the record back on sale and returns the money (simulated). In all three the two existing buttons are now 12 px apart (user-test point about buttons stuck together). Illustrative data.

Option A · A text link under the buttons

"Cancel order" is a quiet underlined link below the two buttons. Tapping it opens a confirmation box. Hard to tap by accident, but easy to miss.
