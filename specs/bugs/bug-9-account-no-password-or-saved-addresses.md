# Bug 9 · Account screen: no password change and no saved addresses

> Found during manual testing · 2026-11-10. Status: fixed 2026-11-10 (design option A).

## Description
On the "Your account" screen I cannot change my password. It should also have my addresses saved, as suggested before: one for delivery and one for billing, which can be different.

## Steps to reproduce
Open the account menu of the user.

## Current vs expected behaviour
**Current:** The "Your account" screen only shows the name and the email. There is no way to change the password and there are no saved addresses.
**Expected:** It should be possible to change the password and to have the delivery address and the billing address saved, as they can be different.

## Customer impact
Poor user experience.

## Priority
P4
