# Bug 8 · No way to message the seller after paying

> Found during manual testing · 2026-11-10. Status: fixed 2026-11-10 (design option A).

## Description
On the order screen, after paying, I cannot send a message to the seller. I do not want to cancel the order, only to talk to the seller, and there is no way to do it.

## Steps to reproduce
After a purchase, go to the user menu.

## Current vs expected behaviour
**Current:** On the order screen (status "Paid"), the only action is the "It arrived, all good" button. There is no way to send a message to the seller.
**Expected:** It should be possible to send a message to the seller without cancelling the order.

## Customer impact
Poor user experience.

## Priority
P4
