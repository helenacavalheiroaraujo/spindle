# Bug 35 · A cart item does not open its listing

> Found in a user test · 2026-11-21. Status: open.

## Description
In the cart, clicking an item does not take me to the listing. If I want to look at the item again, I cannot do it directly.

## Steps to reproduce
1. Put a record in the cart.
2. Open the cart.
3. Click the name of the record.

## Current vs expected behaviour
**Current:** Nothing opens; the text is only selected.
**Expected:** The listing opens.

## Customer impact
Poor user experience

## Priority
P3 Medium
