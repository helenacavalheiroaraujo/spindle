# Bug 25 · Footer text not aligned with header text

> Found 2026-11-11. Status: open.

## Description
The left edge of the text in the footer is not aligned with the left edge of the text in the header.

## Steps to reproduce
1. Open the home page.
2. Scroll to the bottom of the page.

## Current vs expected behaviour
**Current:** The left edge of the footer text is not aligned with the left edge of the header text.
**Expected:** The left edge of the footer text should be aligned with the left edge of the header text.

## Customer impact
Poor user experience
