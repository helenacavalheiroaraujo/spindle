# Bug 7 · The postcode field has no input mask

> Found in feedback on the app · 2026-11-10. Status: open.

## Description
The "Postcode" field has no input mask: I have to type the "-" by hand, even though it is a format the system already knows.

## Steps to reproduce
1. Open the checkout.
2. Type a postcode in the "Postcode" field, for example 1111-111.
3. The hyphen has to be typed by hand.

## Current vs expected behaviour
**Current:** The hyphen in the postcode has to be typed by hand.
**Expected:** The field has an input mask, so the hyphen appears by itself.

## Customer impact
Poor UX.

## Priority
P4
