# Bug 5 · Page space is poorly used

> Found in feedback on the app · 2026-11-10. Status: open.

## Description
The page spacing is poorly used.

## Steps to reproduce
1. Open any page. The problem appears on many of them, for example the list of copies for sale ("4 for sale").

## Current vs expected behaviour
**Current:** The content takes only the left column, and the rest of the page width is empty.
**Expected:** The content uses the full width of the page.

## Customer impact
Poor UX.
